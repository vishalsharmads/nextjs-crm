Bring records in from a spreadsheet: an Excel workbook (.xlsx, the first sheet is read) or a CSV file.

1. Choose the file. The first row must hold column names.
2. Match each column to a field. Columns you skip are ignored.
3. Choose what happens to duplicates: skip them or update the existing record.
4. Start the import. It runs in the background; you can leave the page and come back.

Rows with problems are listed with the reason, so you can fix the file and import just those rows again. You need the import permission for the record type. The uploaded file is deleted when the import ends, and a file you upload but never import is deleted after a day.
